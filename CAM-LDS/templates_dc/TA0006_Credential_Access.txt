======================================================================
  MITRE ATT&CK — TACTIC: TA0006
======================================================================
  ID         : TA0006
  NAME       : Credential Access

  OBJECTIVE  : The adversary is trying to steal account names and passwords.

----------------------------------------------------------------------
  TECHNIQUES USE
----------------------------------------------------------------------

  Credential Access consists of techniques for stealing credentials
  like account names and passwords. Techniques used to get
  credentials include keylogging or credential dumping.

----------------------------------------------------------------------
  OUTCOME / TACTIC LINKS
----------------------------------------------------------------------

  Using legitimate credentials can give adversaries access to
  systems, make them harder to detect, and provide the opportunity
  to create more accounts to help achieve their goals.

----------------------------------------------------------------------
  LINUX DETECTION STRATEGIES
----------------------------------------------------------------------

    Detects unauthorized edits to /etc/hosts, /etc/resolv.conf, or
    suspicious ARP broadcasts.

    Multiple authentication failures for valid or invalid users
    followed by success from same IP/user.

    Detects access to known password store files (e.g., /etc/shadow,
    GNOME Keyring, KWallet, browser credential databases).

    Execve: Suspicious binaries or scripts interacting with
    authentication binaries (sshd, gdm, login).

    Processes reading credential or token cache files.

    Detects use of tools/scripts accessing input devices like
    /dev/input/* or evdev via suspicious processes lacking GUI
    context.

    Detects modification of PAM configuration files, unauthorized
    new PAM modules, and suspicious process execution accessing
    PAM-related binaries.

    Syscalls (open, read, ioctl) on /dev/input or /proc/*/fd/*.

    Pam_unix or pam_google_authenticator invoked repeatedly within
    short interval.

    Detects abnormal NIC configurations and unauthorized sniffing
    from non-root sessions.

    Processes opening /proc/*/mem or /proc/*/maps targeting
    credential-storing services like sshd or login. Behavior often
    includes high privilege escalation and memory inspection tools
    such as gcore or gdb.

    Ptrace syscall or access to /proc/*/mem. Open or read to browser
    cookie storage.

    Execve: openssl pkcs12, certutil, keytool. Open, read:
    /etc/ssl/, /etc/pki/, ~/.pki/nssdb/.

    Access to /var/lib/sss/secrets/secrets.ldb or .secrets.mkey.

    Execution of tools like cat, grep, or awk on credential files.
    Open/read system calls to ~/.bash_history or /etc/shadow.
